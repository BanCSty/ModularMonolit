# Shared Library

Библиотека общих компонентов для всех модулей системы

## 🎯 Назначение

`Shared` — это набор независимых библиотек, которые предоставляют:
- **Контракты** для взаимодействия модулей
- **Инфраструктуру** для событийной модели
- **Реализацию** Transactional Outbox Pattern
- **Утилиты** для общей конфигурации

## ⚠️ Важно: Правила использования

Сюда попадает **только** то, что:
- ✅ Нужно **всем** модулям
- ✅ Не содержит **бизнес-логики**
- ✅ Является **контрактом** между модулями
- ✅ Стабильно и не зависит от конкретного модуля

**Что НЕ должно попадать в Shared:**
- ❌ Бизнес-логика конкретного модуля
- ❌ Специфичные для модуля сущности
- ❌ Реализации сервисов модулей

Shared/
