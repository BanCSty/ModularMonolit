# Shared.Infrastructure

Общие инфраструктурные утилиты.

## 🎯 Назначение

Вспомогательные классы для решения **инфраструктурных** задач, не зависящих от конкретного модуля.

## 📦 Содержимое

### `DatabasePathHelper`

Помощник для определения пути к файлам баз данных.

## Зачем это нужно?
- Проблема: При запуске dotnet ef migrations\update из директории модуля БД создаётся в самом модуле, а мне бы хотелось все БД иметь в API для удобства.
- Решение: DatabasePathHelper находит корень solution и помещает все БД в src\ModularMonolit\data.
